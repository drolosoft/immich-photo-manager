# Demo media for immich-photo-manager

This branch only serves files through GitHub Pages. The plugin, the docs and the
demo transcripts live on `main`. Files here are the ones too large for the Claude
directory's plugin folder limits: the animated demo page and the video and PDFs
behind demo 12.

- https://drolosoft.github.io/immich-photo-manager/assets/demo.html
- https://drolosoft.github.io/immich-photo-manager/doc/demos/assets/12/luna.mov
- https://drolosoft.github.io/immich-photo-manager/doc/demos/assets/12/luna-photobook.pdf
- https://drolosoft.github.io/immich-photo-manager/doc/demos/assets/12/moon-evening-report.pdf

To edit the demo page, check this branch out as a worktree:

    git worktree add ../immich-photo-manager-pages gh-pages
